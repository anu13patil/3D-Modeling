## 📐 Project Overview

A piston is a core component of reciprocating engines and pumps. It moves inside the cylinder, transferring force from expanding gases to the connecting rod via the piston pin. This project models a simplified piston with its key features.

### Design Features

- **Flat piston crown** – the top surface that faces the combustion chamber
- **Ring grooves** – three grooves near the top, which hold the piston rings that seal the cylinder and control oil
- **Piston skirt** – the smooth cylindrical lower body that guides the piston within the cylinder
- **Gudgeon (wrist) pin hole** – the side hole that connects the piston to the connecting rod
